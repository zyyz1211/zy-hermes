# Chinese Enterprise Parent Mapping (中国企业母公司映射)

## 工作流

### 1. 提取唯一业主名
从 Excel 的指定列提取所有不重复值：

```python
import openpyxl
from collections import defaultdict

wb = openpyxl.load_workbook(path, data_only=True)
ws = wb['项目收尾']  # ⚠️ 始终用名称引用，不用 ws.active
owners = set()
for row in ws.iter_rows(min_row=4, max_col=8, max_row=ws.max_row, values_only=True):
    val = row[7]  # H列
    if val and str(val).strip():
        owners.add(str(val).strip())
```

### 2. 构建映射字典
用三级策略构建映射：

**第一级：集团模式匹配** — 用 `re.search` 匹配知名集团前缀
**第二级：精确名称字典** — 用 `dict` 存储精确匹配
**第三级：自母公司** — 对于本身就是母公司的独立实体，返回自身名称

### 3. 写入 Excel（⚠️ 关键陷阱）

**`openpyxl` 的 `ws.active` 在保存到新文件时可能指向错误 sheet！**
修复方法：始终用名称引用 sheet。

```python
# ❌ 错误：有时会新建"Sheet1"而非修改目标 sheet
ws = wb.active
ws.insert_cols(9)

# ✅ 正确：显式指定 sheet 名称
ws = wb['项目收尾']
ws.insert_cols(9)
ws.cell(row=3, column=9, value='母公司名称')

# 清理 openpyxl 可能创建的额外 sheet
while 'Sheet1' in wb.sheetnames:
    del wb['Sheet1']
```

### 4. 验证输出
```python
wb2 = openpyxl.load_workbook(output_path, data_only=True)
ws2 = wb2.active
assert ws2.title == '项目收尾', f"Wrong sheet: {ws2.title}"
assert ws2.cell(row=3, column=9).value == '母公司名称'
```

## 已知陷阱

1. **`ws.active` 不可靠** — 始终用 `wb['项目收尾']` 显式引用
2. **"中化"前缀歧义** — `中化二建` 属于某工程集团（CNCEC），`中化泉州` 属于中国中化控股（Sinochem）。用 `re.match(r'^中化(?!学)(?!二建)(?!建)', owner)` 区分
3. **"天辰"歧义** — `中国天辰工程有限公司` = CNCEC，但 `天辰化工有限公司` 是独立公司
4. **`openpyxl` 可能创建额外 "Sheet1"** — 保存前删除
5. **`data_only=True`** 读取公式结果，但保存时公式不会保留
