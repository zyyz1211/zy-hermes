# 季度绩效考核指标设定与自评填写

根据个人周报（滚动计划）和督办任务清单，完成季度绩效考核的两个环节：
1. **季初**：设定绩效指标（工作任务名称、工作目标、权重）
2. **季末**：填写完成情况（自评明细）

## 重要原则：考核维度每季度不同

⚠️ **5个考核维度不是固定的**。每个季度需要根据用户的实际工作重心重新确定维度。不能沿用上季度维度不变。

### 维度确定方法

打开季度考核表后，结合以下信息判断维度是否需要调整：

1. **督办任务清单**（`D:\<知识库>\集团督办工作-个人工作任务\个人督办任务清单.md`）— 查看哪些督办任务在本季度有节点
2. **近期周报** — 查看用户实际在做的工作
3. **用户说明** — 用户可能会告知某项工作降权或新增

### 维度命名惯例

- 督办任务应显式标注在对应维度的工作目标中，用（督办任务N）标记
- 如果某维度融入了督办内容，可以考虑改名以体现（如"大客户管理工作"→"大客户管理及战略合作"）
- 督办任务数量较多的维度，可以考虑改名"专项工作及督办任务"

## 执行步骤

### 1. 读取所有周报

用 Python (openpyxl) 读取 `定` 目录下所有周报 xlsx 文件。重点关注：
- **本周总结**部分：已完成的工作事项
- **下周工作重点**部分：计划中的事项（可辅助判断工作方向）

周报文件名按 `w` 后面的周数排序（如 w17~w25 对应二季度）。

### 2. 提取关键工作事项

按考核维度归类，从周报中提取对应关键词的工作：

**市场开发**：拜访记录、央企对接、区域调研、市场分析
**商务接待**：会务筹备、文字材料、行程安排
**大客户管理**：客户档案、战略协议、对接服务
**专项工作**：PPT制作、规划编制、政策研究、督办
**其他**：征文、材料报送、评选、临时工作

### 3. 生成完成情况文本

格式要求：
- 每条用 `N.` 编号，换行分隔
- 内容具体，包含客户名称、事项名称等细节
- 语言正式、精炼，符合国企公文风格
- 每个维度3-5条即可，不求全但求准

### 4. 写入 Excel

用 openpyxl 打开考核表，在 H列（第8列）写入完成情况：
```python
from openpyxl.styles import Alignment, Font
cell.alignment = Alignment(horizontal='left', vertical='top', wrap_text=True)
cell.font = Font(name='Calibri', size=11)
```

## 输出

- 覆盖原考核表文件
- 路径：`C:\Users\<user>\Desktop\05_周报述职\季度绩效考核\`
- 格式：`2026年X季度自评明细.xlsx`

## 脚本模板

```python
# -*- coding: utf-8 -*-
import openpyxl
from openpyxl.styles import Alignment, Font

src = r"C:\Users\<user>\Desktop\05_周报述职\季度绩效考核\2026年X季度自评明细.xlsx"
wb = openpyxl.load_workbook(src)
ws = wb.active

# 根据周报分析填写每个维度的完成情况
completions = {
    3: "填写市场开发相关工作完成情况...",
    4: "填写商务接待相关完成情况...",
    5: "填写大客户管理相关完成情况...",
    6: "填写专项工作相关完成情况...",
    7: "填写其他工作完成情况...",
}

for row_num, content in completions.items():
    cell = ws.cell(row=row_num, column=8)
    cell.value = content
    cell.alignment = Alignment(horizontal='left', vertical='top', wrap_text=True)
    cell.font = Font(name='Calibri', size=11)

wb.save(src)
```

## 注意事项

1. 考核表模板的列结构必须一致（A=考核方式, B=工作任务名称, C=任务分类, D=指标来源, E=指标性质, F=权重, G=工作目标, H=完成情况, I=附件）
2. 完成情况要写实、写具体，避免空话套话
3. 季度周期一般为第17周至第25周左右（4月-6月），实际以周报文件为准
4. 周报中的「下周工作重点」只作参考，不作为完成依据
