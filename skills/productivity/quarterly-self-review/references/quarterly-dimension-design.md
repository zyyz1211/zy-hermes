# 季度考核维度设计方法

## 核心原则

**每个季度的5个考核维度不是固定的。** 必须根据用户当前季度的实际工作重心来设计，不能简单沿用上季度。

## 设计流程

### 输入数据

1. **近期周报**（`定` 目录中的 `w*` 文件）
2. **督办任务清单**（`D:\<知识库>\集团督办工作-个人工作任务\个人督办任务清单.md`）
3. **用户说明** — 用户可能主动告知某项工作降权或新增

### 步骤

#### 第一步：梳理用户当前工作内容

从周报和督办清单中提取用户实际在做的事项。用户的职责核心在经营管理部，围绕四条主线：
- **市场开发** — 客户拜访、区域拓展、央企对接
- **大客户/战略合作** — 客户档案、战协起草/签订/跟踪
- **高端经营/商务** — 高层商务活动、接待筹备
- **专项工作** — 政策研究、规划编制、督办任务

#### 第二步：对照督办任务清单

打开督办清单，查看哪些任务在本季度有截止节点：

| 督办任务 | 截止日 | 归属维度 |
|:---------|:------:|:---------|
| 1. 设备更新市场开发 | 10月31日 | 市场开发 |
| 2. 节能降碳联合 | 6月30日⚠️ | 市场开发/战略合作 |
| 3. 富海/东明项目介入 | 8月30日 | 大客户管理 |
| 4. 节能降碳培训 | 8月30日 | 专项工作 |
| 5. 海南自贸港研究 | 9月30日 | 专项工作 |
| 6. 某水电项目投标≥3个 | 9月30日 | 市场开发 |
| 7. 高端经营战协≥5份 | 已办结 | — |
| 8. 高端经营活动≥5次 | 11月30日 | 高端经营 |
| 9. 粤港澳对接 | 12月31日 | 市场开发 |
| 10. 粤港澳分析报告 | 12月31日 | 专项工作 |

#### 第三步：设计维度

模板结构（5个维度，各20%）：

| # | 维度 | 分类 | 督办融入策略 |
|:-:|:-----|:----:|:-------------|
| 1 | 参与市场开发有关工作 | 重点工作 | 归入：设备更新、节能降碳联合、某水电项目、粤港澳对接 |
| 2 | 大客户管理及战略合作 | 重点工作 | 归入：富海/东明项目介入、战协跟踪落实 |
| 3 | 协助开展高端经营有关工作 | 重点工作 | 归入：高端经营活动策划组织 |
| 4 | 专项工作及督办任务 | 日常工作 | 归入：海南自贸港研究、节能降碳培训、粤港澳分析 |
| 5 | 其他工作 | 日常工作 | 归入：临时交办、十五五配合、生态环保督察 |

#### 第四步：标记督办来源

在工作目标的对应条目后标记 `（督办任务N）`，便于季末填写完成情况时对照。

## 常用维度改名模式

| 原名 | 改名 | 场景 |
|:-----|:-----|:-----|
| 协助筹备商务接待、拜访 | 协助开展高端经营有关工作 | 督办中高端经营比重加大时 |
| 大客户管理工作 | 大客户管理及战略合作 | 战略合作协议签署/跟踪是重点工作时 |
| 有关专项工作 | 专项工作及督办任务 | 督办任务数量多、覆盖广时 |

## 季度对照

| 季度 | 周次范围 | 特殊注意 |
|:----:|:---------|:---------|
| 一季度 | 1-13周 | 年初指标设定、年度工作部署 |
| 二季度 | 14-26周 | 十五五规划编制高峰、客户拜访密集 |
| 三季度 | 27-39周 | 十五五进入发布实施、督办任务节点集中 |
| 四季度 | 40-52周 | 年度总结、督办收尾、下年规划 |

## 注意事项

- 十五五规划在三季度进入发布和组织实施阶段，不再是大头工作，应归入"其他工作"而非独立维度
- 已办结的督办任务（如任务7）成果延续但不再作为当前考核重点
- 每季度末填写完成情况时，督办任务的反馈记录也要参考
