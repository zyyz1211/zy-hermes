# 企业专项行动方案批量重命名案例

## 场景

用户提供企业规范简称排序表：`附件：所属企业规范简称.xlsx`，要求将文件夹中的专项行动方案按企业顺序加序号。

排序表示例：

| 序号 | 内部规范简称 | 外部规范简称 |
|---|---|---|
| 1 | 天辰公司 | 某工程集团天辰公司 |
| 2 | 赛鼎公司 | 某工程集团赛鼎公司 |
| 3 | 东华公司 | 某工程集团东华公司 |

## 用户纠正

第一次简单命名为：

```text
01_天辰公司-5.2026年公司经营管理价值提升专项行动方案.pdf
```

用户认为错误。正确应为：

```text
01_天辰公司2026年公司经营管理价值提升专项行动方案.pdf
```

## 正确处理逻辑

1. 读取 Excel 排序表，建立别名：企业全称、内部简称、外部简称。
2. 匹配文件名中的企业。
3. 目标序号来自 Excel 表，不来自文件名。
4. 目标企业名使用“内部规范简称”。
5. 清理文件名正文：
   - 删除已有序号前缀：`^\d{2}[_＿]`
   - 删除企业名后的分隔符：`-`、`—`、`：`、`、`、`.`、空格等
   - 删除材料编号：`5.`、`5-`、`3：`、`4、`
   - 删除重复企业名/企业全称
   - 保留年份：`2026年度`、`2026年`

## 正则注意点

删除材料编号时不要用 `^\d+`，否则会误删年份 `2026`。

推荐：

```python
LEADING_DOC_NO_RE = re.compile(r"^\s*\d{1,2}\s*[\.．、:：\-—_＿]\s*")
```

这个规则只删除带标点的 1-2 位材料编号，不会删除 `2026年度`。

## 最终示例

```text
01_天辰公司2026年公司经营管理价值提升专项行动方案.pdf
02_赛鼎公司2026年度经营管理价值提升专项行动方案.docx
03_东华公司2026年度经营管理价值提升专项行动方案-定稿.docx
03_东华公司2026年度经营管理价值提升专项行动清单-定稿.xlsx
04_五环公司2026年度经营管理价值提升专项行动方案.docx
```

## 未匹配文件

如果排序表没有该企业（如“西部新材”），不要擅自编号。保持原名并在最终回复中说明：排序表中无该企业，因此未处理。
