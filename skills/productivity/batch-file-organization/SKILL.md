# Batch File Organization — 批量文件整理与规范命名

## When to use

用户要求对本地文件夹内容进行**批量重命名、排序编号、按 Excel 映射表添加前缀、清理文件名、移动日志/脚本**时使用。典型场景：

- 按企业排序表将文件命名为 `01_天辰公司...`、`02_赛鼎公司...`。
- 按时间/会议顺序将 PDF 命名为 `01+文件名`、`02+文件名`。
- 文件夹里有 Word/PDF/Excel 等混合文件，需要保留扩展名并统一命名格式。
- 用户强调“桌面不能乱”“脚本放到 09_工具脚本”。

## Core workflow

1. **先列清单**
   - 用文件搜索工具列出目标文件夹文件。
   - 如果需要参考 Excel 排序/简称表，用 Windows Python + `openpyxl` 读取表格内容。
   - 不要凭印象猜序号；以用户给的表为准。

2. **建立映射规则**
   - 从 Excel 中读取：序号、公司名称、内部规范简称、外部规范简称。
   - 同一企业要支持多个别名匹配，如 `天辰公司`、`某工程集团天辰公司`、企业全称。
   - 多个别名命中时，优先使用最长别名，避免短词误匹配。

3. **先预览，再执行**
   - 批量改名必须先生成 `原文件名 -> 新文件名` 预览。
   - 检查未匹配文件，未匹配的不擅自编号，保持原名并报告原因。
   - 如用户已授权直接执行，可在预览合理后继续执行，但仍要保留日志。

4. **两阶段重命名**
   - 先把源文件改成临时名，再改成目标名，避免 `01_...` 与原名互相冲突。
   - 检查目标名重复；若重复，要加 `_2` 或按业务含义区分，不要覆盖。

5. **生成映射日志并核验**
   - 在日志中记录时间、目标文件夹、依据表、原文件名、新文件名、未匹配文件。
   - 最后重新列出目标文件夹，确认真实文件名已符合预期。
   - 用户不希望目标业务文件夹混入日志时，将日志移到 `C:\Users\<user>\Desktop\09_工具脚本\`。

## Naming rules learned from 用户

### 企业专项行动方案类文件

用户纠正过：**不要简单把序号接到完整原文件名前面**。例如错误形式：

```text
01_天辰公司-5.2026年公司经营管理价值提升专项行动方案.pdf
```

正确形式应清理掉原始材料编号、连接符和重复企业名：

```text
01_天辰公司2026年公司经营管理价值提升专项行动方案.pdf
02_赛鼎公司2026年度经营管理价值提升专项行动方案.docx
```

规范化原则：

- 格式：`{两位序号}_{企业内部规范简称}{正文主题}.{原扩展名}`。
- 去掉既有序号前缀：`01_`、`02_` 等。
- 去掉企业简称后的连接符：`-`、`—`、`：`、`、`、`.`。
- 去掉材料自带编号：`5.`、`5-`、`3：`、`4、` 等。
- 去掉重复企业简称/企业全称：如 `赛鼎公司-5.赛鼎公司2026...` 只保留一个 `赛鼎公司`。
- **保留年份**：`2026年度`、`2026年` 不能被当成材料编号删掉。
- 清理 `2026 年度` 这类多余空格为 `2026年度`。
- 同一企业多个文件可以共用同一序号，如东华公司方案和清单都可为 `03_...`。

### 时间顺序编号类文件

- 如用户要求“按时间顺序 `01+文件名`”，可保留原文件名，只加 `01+` 前缀。
- 若文件名中有年份/会议名称，优先按文件名推断实际会议时间；文件系统修改时间通常不可靠。
- 生成 `rename_log_时间.txt` 记录排序依据。

## Script conventions

- 工具类 Python 脚本保存到：
  - Windows: `C:\Users\<user>\Desktop\09_工具脚本\`
  - MSYS/Git Bash: `/c/Users/<user>/Desktop/09_工具脚本/`
- Python 文件必须有 `# -*- coding: utf-8 -*-`。
- 所有 `open()` / `Path.write_text()` / `Path.read_text()` 必须显式 `encoding='utf-8'`。
- Windows 路径优先用 raw string：`Path(r"C:\...")`。
- 涉及 `openpyxl` 时，优先用 Windows Python `python`；如 `python3` 无包，不要把“缺包”固化为失败结论。

## Verification checklist

- [ ] 文件数量改名前后一致。
- [ ] 每个已匹配文件都有正确两位序号。
- [ ] 企业简称符合 Excel 的“内部规范简称”。
- [ ] 没有残留原始材料编号，如 `-5.`、`3：`。
- [ ] 年份没有被误删，如 `2026年度` 仍保留。
- [ ] 未匹配文件已列出并说明原因。
- [ ] 目标文件夹没有临时文件、脚本或不需要的日志污染。

## Pitfalls

- ❌ 不要只做 `01_ + 原文件名`，这会保留杂乱编号和重复企业名。
- ❌ 不要用宽泛正则删除开头数字，否则会把 `2026年度` 误删成 `年度`。
- ❌ 不要覆盖同名文件；必须先检查冲突。
- ❌ 不要擅自给 Excel 表中不存在的企业编号；未匹配文件保持原名并报告。
- ❌ 不要把临时脚本和日志散放桌面或业务文件夹；脚本/日志归档到 `09_工具脚本`。
