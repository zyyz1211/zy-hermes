# 业主→母公司映射技能

## 适用场景

化工/工程类 Excel 报表（如收尾项目月报），需要在 H 列（业主名称）后插入 I 列（母公司名称）。

## 用法

运行脚本 `apply_mapping.py`，自动读取 Excel、插入列、映射母公司。

```bash
python apply_mapping.py
```

修改脚本顶部的 `input_path` 和 `output_path` 即可应用到其他文件。

## 映射规则说明

1. **央企集团匹配** — 按名称前缀匹配主要央企集团（某工程集团工程、中石化、中石油、中海油、国家能源、中煤、陕煤、延长石油等 30+ 集团）
2. **地方能源/化工集团** — 山东能源、华谊集团、天津渤化、贵州磷化、云南能投等 50+ 集团
3. **化工/民企集团** — 万华化学、恒力、荣盛、盛虹、宜化、兴发等
4. **外企映射** — BASF、SABIC、Arkema 等 30+ 家外企
5. **自持母公司** — 无明确母公司的独立企业保留原名
6. **政府单位** — 匹配人民政府、局、委员会等政府主体

## 注意事项

- 输入文件 H 列为业主名称，表头在第 3 行
- 输出在源文件同目录加 `_带母公司` 后缀
- 映射基于名称模式匹配，覆盖率约 40-50%
- 未匹配的留空，可后续手动补充
