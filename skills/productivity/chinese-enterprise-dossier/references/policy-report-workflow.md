# 政策研究报告工作流 (Policy Research Report Workflow)

从企业领导视角审阅/撰写政策研究报告 — 将泛化内容转化为针对性的、定量化的战略建议。

## 触发条件

用户要求审阅/修改/撰写一份政策或行业研究报告，且要求从"集团领导视角"或"公司视角"出发。

## 工作流 (5步)

### Step 1: 读取和理解原始报告

使用 python-docx 提取文档全部段落和表格：

```python
import docx
doc = docx.Document(path)
for i, p in enumerate(doc.paragraphs):
    if p.text.strip(): print(f'[{i}] {p.text}')
```

关注：目标/结构/当前泛化程度/空缺点。

### Step 2: 搜索集团在相关领域的实际布局

使用 `delegate_task` 系统化搜索。搜索维度：

| 维度 | 关键词示例 | 信息来源 |
|------|-----------|---------|
| 集团层面 | "某工程集团工程 海南 子公司" | 百度/企查查/天眼查 |
| 二级企业 | "天辰公司 海南"、"六建 海南分公司" | 行业新闻 |
| 项目层面 | "某工程集团 海南 项目" | 招标公告/项目新闻 |
| 政策层面 | "海南自贸港 鼓励类产业 目录 2024 石化" | 政府官网 |
| 相关产业 | "洋浦 石化 产业园" | 行业报告 |

**关键提示：** 用户可能比公开信息更了解内部组织架构，搜索后主动询问用户补充未公开信息。

### Step 3: 确定信息映射关系

将报告中的泛化表述替换为具体实体含量化：

| 泛化表述 | 替换为 |
|---------|-------|
| "驻琼企业" | 某集团海南子公司、六建海南分公司、某集团海南子公司 |
| "企业成本" | 量化：深海能源项目进口设备可省数百万元 |
| "税收红利" | 量化：年利润5000万×10%税率差=年省税约500万元 |
| "鼓励类产业" | 引用《海南自由贸易港鼓励类产业目录（2024年本）》具体条款 |

已知集团在琼实体列表见 `references/hainan-layout.md`。

### Step 4: 新增"结论与建议"章节

从泛化结论升级为6-8条可执行建议，每条包含：
- **操作主体**（哪家公司/哪个部门）
- **具体行动**（做什么）
- **量化目标**（省多少钱/省多少税）
- **时间节点**（何时完成）

### Step 5: 生成文档

使用 `templates/report-generator.py` 生成公文格式文档。

## 关键原则

1. **每条数据必须可溯源** — 子公司名称、注册资本、合同额等来自公开信息或用户确认
2. **不编造集团不存在的实体** — 搜索不到则标注"据公开信息暂无"
3. **用户是信息源** — 内部架构信息主动询问
4. **定量优于定性** — "省税约500万元"比"降低税负"更有说服力
5. **领导视角** — 战略高度（"纳入十五五规划"、"RCEP+海南双15%叠加"等宏观视角）

## 注意事项

- 公文格式一致性（黑体标题、仿宋正文、宋体表格）
- 量化数据标注来源
- 避免空泛建议
- 文件被 Word 锁定时加 `_v{YYYYMMDD}` 后缀
