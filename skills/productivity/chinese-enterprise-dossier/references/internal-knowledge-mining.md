# 内部知识库主题挖掘工作流

## 适用场景

从集团领导讲话PDF文件集合中，提取与特定主题（如"海外"、"科技创新"、"党建"等）相关的内容，进行跨文档交叉分析，用于：

- 补充完善汇报材料
- 提炼领导讲话口径和要点
- 梳理某个主题在时间线上的演进
- 比对不同文件中同一主题的表述一致性

## 环境注意事项

| 项目 | 说明 |
|------|------|
| 路径 | Windows路径在MSYS中用 `/d/<知识库>/...` 格式 |
| 搜索陷阱 | `search_files`（ripgrep）无法搜索PDF内部，且对中文路径可能失败 |
| 提取工具 | pymupdf（fitz）— 对中文PDF文本提取效果好，无需OCR |
| Python | 可用 `python`（Windows Python 3.13） |

## 工作流

### Step 1: 发现文件集合

```bash
ls -la "/d/<知识库>/集团领导讲话/"
```

列出所有PDF文件，观察文件名中的编号和主题，快速了解语料库范围。

注意：文件名中的中文书名号 `《》`、空格等特殊字符在MSYS中需用引号包裹。

### Step 2: 安装/验证提取工具

```bash
python -c "import fitz; print('pymupdf OK:', fitz.__version__)"
```

如未安装：`pip install pymupdf`

### Step 3: 提取所有PDF文本并搜索目标主题

```python
import fitz, os, glob, re

files = sorted(glob.glob("*.pdf"))
results = {}

for f in files:
    doc = fitz.open(f)
    text = ""
    for page in doc:
        text += page.get_text()
    doc.close()
    
    # 统计关键词出现次数
    counts = {}
    for term in ['海外', '国际化', '走出去', '一带一路', '境外', '全球']:
        c = text.count(term)
        if c > 0:
            counts[term] = c
    
    # 提取关键词所在的完整句子（以句号/分号分割）
    hits = []
    for m in re.finditer(r'[^。]*?(?:海外[^。]*?)[。；]', text):
        s = m.group().strip()
        if len(s) > 5:
            hits.append(s)
    
    results[f] = {'pages': len(doc) if hasattr(doc, 'page_count') else 0, ...}
```

**关键技巧：**
- 用 `re.finditer(r'[^。]*?关键词[^。]*?[。；]', text)` 提取完整中文句子
- 先用 `.count('关键词')` 快速判断哪些文件有内容，再深入提取
- 多词搜索时分开统计，不要合并到同一个正则

### Step 4: 跨文档对比分析

完成提取后，按以下维度组织结果：

| 维度 | 做法 |
|------|------|
| **频次排序** | 哪个文件提及最多（通常是专题讲话） |
| **时间线** | 不同年份文件中该主题的表述变化 |
| **口径一致性** | 关键提法是否统一（如"一体两翼"→"一体两翼") |
| **数据/案例** | 各文件中的具体数据、项目名称、国别 |

### Step 5: 合成输出

用结构化格式呈现：

- **概述**：该主题在语料库中的总体覆盖情况（多少文件涉及、核心文件是哪个）
- **横向对比表**：各文件的关键语句/数据/观点
- **核心文件深度摘要**（如有专题讲话）：大纲框架
- **补充建议**：针对用户已有材料的改进点

### Step 6: 用知识库内容丰富已有材料

将知识库中的表述与用户已有草稿逐段比对：

1. 先保留用户原文中的有效内容
2. 从知识库中提取**用户未写但有价值**的补充点（新机构、新项目、新表述）
3. 按"补充点→来源→说明"做条目化标注
4. 可在完善稿中用 **加粗** 或 ⚠️ 标注需要用户确认的数据（PDF中脱敏的 **** 数据）

## 典型输出格式

```
🏠 目录总览：共 N 个文件，涉及该主题的 M 个
📄 核心文件：标题（频次最高）
📄 其他相关文件：标题列表

按文件逐一呈现：
📄 文件名
   关键词频次统计
   核心句子（前 5-10 条）

跨文档总结表
```

## 常见陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| grep搜索PDF失败 | search_files返回0结果 | 必须用pymupdf提取文本后搜索 |
| PDF文字是图片 | pymupdf提取为空串 | 需用marker-pdf做OCR |
| 中文PDF字符乱码 | 提取后含大量空白/乱码 | `python` (Win) 而非 `python3` (WSL) |
| PDF数据脱敏 | 出现 **** 占位 | 标注"需用户确认具体数据" |
| 文件名特殊字符 | MSYS路径解析错误 | 用双引号包裹路径 |
