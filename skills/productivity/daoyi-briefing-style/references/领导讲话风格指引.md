# 领导讲话风格指引

> 从集团领导讲话知识库 PDF（`D:\<知识库>\集团领导讲话\`）中提取的正式文稿改写规范。
> 适用于为党委宣传部、品牌文化部等部门提供经营情况汇报材料的场景。

## 适用场景

- 为宣传部/品牌文化部提供**市场经营情况**素材
- 将内部经营数据**改写为领导讲话风格**
- 围绕指定主题（市场销售、市场占有率、海外经营等）组织专项材料

## 风格总则

### 1. 动词选择 —— 用"升级版"替代平实表述

| 平实表述 | 领导讲话风格 |
|---------|-------------|
| 新签合同额X亿元 | 新签合同额**跨越**X亿元 |
| 占比80% | 占比**首次达**80%**以上** |
| EPC占比60% | EPC占比首年**迈过**60%**大关** |
| 新能源项目X亿 | 新能源项目**突破**X亿元 |
| 同比增长10% | 同比增长10%，**再创历史新高** |
| 结构优化 | 经营结构**持续优化**，主责主业**更加聚焦** |
| 设备更新增长26% | 抢抓大规模设备更新政策红利，……同比增长26%，**创历史新高** |
| 海外合同增长 | 海外新签合同额**均实现两位数增长**，**稳固**海外千亿大盘 |
| 品牌影响力提升 | 全球影响力**持续攀升**，"金名片"**成色更足** |
| 中标率高 | 重点战略客户项目中标率**持续提升**，行业竞争位势**持续巩固** |

### 2. 段落结构

**第一段：总述 / 定性**
首句用概括性语言给整段定性，然后跟数据支撑。模式：
- 「**……稳中有进。** 2025年，集团公司……」
- 「**……量质齐升。** 深入实施……」
- 「**……释放乘数效应。** 引领所属企业……」
- 「**……加速成势。** 积极拓展……」

**中间段：用"一是……二是……三是……"平行展开**
- 「坚持'基础+高端'双向发力，推动经营模式迭代升级。**深入实施**'T+EPC'模式……**积极拓展**新能源……**抢抓**大规模设备更新政策红利……」

**收尾段：提炼高度**
- 「行业领先地位**进一步巩固**」
- 「'某工程集团'品牌的全球美誉度和市场认可度**进一步增强**」
- 「领航出海'金名片'**成色更足**」

### 4. 三板块数据组织法

当被要求围绕"市场销售"和"市场占有率"组织材料时，标准三段式：

```
## 一、市场销售情况

### （一）国内市场稳中有进
[总业绩 → 结构优化 → 模式创新 → 专项突破]

### （二）海外市场量质齐升
[海外业绩 → 战略执行 → 国别/赛道突破 → 重大项目 → 品牌影响力]

## 二、市场占有率情况
[国内核心客户 → 中标率/份额 → 海外市场影响 → 品牌认可度]
```

各板块内部节奏：**定性句开头 → 具体数据 → 意义收束**。

### 5. 数据呈现要点

- **对比用"同比增量"**：不说"比去年多X亿"，说"同比增量超X亿元"
- **里程碑用"首次""首年"**：首次突破X亿元、EPC占比首年迈过60%大关
- **高增长用"创历史新高"**：同比增长26%，创历史新高
- **多指标用"均实现两位数增长"**：干净利落，不逐个报%
- **份额数据用"超65%""超过90%"**：保留数字但用"超"字增加气势感
- **对外口径注意**：给品牌文化部/宣传部的材料中，"市场占有率"可保留具体数字；若对方明确要求对外口径，则改为"保持行业领先优势""中标率持续提升"等定性表述

### 6. 禁忌

- **不要平铺直叙**："新签合同额X亿元，增长10%" → 需加动词修饰
- **不要堆砌数据不分主次**：每个段落最多2-3个关键数字
- **不要用"我们"开头**：用"集团公司""集团"保持正式感
- **不要在结尾突然弱化**：每段结尾应是"进一步巩固""持续提升"等上升收束，而不是"仍需努力"等弱化表述
- **不要把内部字段带入**：不写"客户等级/商机阶段/合同转化率"等内部管理术语，除非宣传部明确要求
