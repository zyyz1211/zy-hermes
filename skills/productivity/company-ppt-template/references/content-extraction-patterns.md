# 从文档提取PPT内容的模式参考

## 场景：大型数据表格报告 → PPT

当源文档包含大量项目数据表格（如煤制油项目分析报告，386行、19个项目含详细参建单位信息），按以下模式处理：

### 1. 识别内容层次

原始文档通常有三个层次：

| 层次 | 示例 | PPT处理方式 |
|------|------|-------------|
| **顶层结论** | 总体概况、结论 | 做成独立幻灯片，每页3-5个要点 |
| **分组数据** | 已建成/在建/拟建分组 | 每类做1页概览，不逐项目罗列 |
| **明细表格** | 项目名称/规模/参建单位等 | 不直接放入PPT，作为"备注"或"附录参考" |

### 2. 提取关键数字

从文档中提取的优先数字类型：
- 总量数据：已建成约970万吨/年、在建约720万吨/年、拟建超3500万吨/年
- 对比数据：最大项目（神华宁煤400万吨）、独特项目（全球唯一煤直接液化）
- 趋势数据：伊泰大路200万吨停建、新疆规划超1700万吨/年

### 3. 结构化JSON输出模板

```json
[
  {
    "layout": "title",
    "title": "报告标题",
    "subtitle": "截至日期/数据截止时间"
  },
  {
    "layout": "content",
    "title": "一、核心章节",
    "subtitle": "（一）子标题",
    "body": [
      "关键数据1：xxx（占比XX%）",
      "关键数据2：xxx（同比增长XX%）",
      "区域分布：A区XX、B区XX、C区XX"
    ]
  },
  {
    "layout": "section",
    "title": "章节分隔页标题"
  },
  {
    "layout": "content",
    "title": "二、分类型分析",
    "body": [
      "类型A（N个，合计XX万吨/年）：",
      "  代表项目1：XX万吨（特点描述）",
      "  代表项目2：XX万吨（特点描述）",
      "类型B（N个，合计XX万吨/年）："
    ]
  },
  {
    "layout": "end"
  }
]
```

### 4. 注意事项

- **参建单位信息**：如果报告中涉及甲方（如某工程集团）参建项目，单独整理为一页"参建情况概览"，而不是散落在各页中
- **停建/暂缓项目**：单独标注，体现审慎态度
- **数据准确性**：所有数字必须与原文一致，不要四舍五入改变量级
- **页数控制**：12-15页最佳，含封面和结束页
