# 周滚动计划 Excel 格式样式分析

基于 `周滚动计划_第19周.xlsx`（<姓名>模板，2026年5月4日-10日）读取的实际值。

## 基本信息

| 属性 | 值 |
|------|-----|
| Sheet 名称 | 编辑人姓名（生成时改为"用户"或其他人名） |
| 合并单元格 | A1:A2 |
| 总行数 | 20 |
| A列宽 | 95 |

## 逐行样式

### A1 (merged A1:A2)
- 值：`某工程集团经营管理部\n周滚动计划`
- 字体：宋体 20pt，加粗
- 对齐：居中/居中，自动换行
- 行高：Row1=34, Row2=48

### A3
- 值：`姓名：<姓名>         第19周  2026年05月04日至2026年05月10日      `
- 字体：宋体 16pt，加粗
- 对齐：居中/居中
- 行高：30

### A4
- 值：`本周总结：`
- 字体：黑体 12pt，加粗
- 对齐：左/居中
- 行高：24

### A5~A10（本周总结内容）
- 示例：`一、完成某综合集团和某市市政府战略合作协议的评审流程。`
- 字体：宋体 12pt
- 对齐：左/居中，自动换行
- 行高：30（A8注释放22，A9/A10置顶放24）

### A11
- 值：`下周工作重点：`
- 字体：黑体 12pt，加粗
- 对齐：左/居中
- 行高：24

### A12~A17（下周计划）
- 字体：宋体 12pt
- 对齐：左/居中，自动换行
- 行高：按内容量调整（24~55不等）

## 生成时关键要求

1. 标题区域 A1:A2 合并 + 宋体 20pt 加粗 + 居中
2. 姓名行 A3 宋体 16pt 加粗 + 居中
3. 分类标题（本周总结/下周工作重点）用黑体 12pt 加粗
4. 内容正文用宋体 12pt（不加粗）+ 自动换行
5. 内容编号统一用中文数字（一、二、三...）
6. 每天计划格式：`一、6月1日 周一：\n  1.任务一。\n  2.任务二。`
