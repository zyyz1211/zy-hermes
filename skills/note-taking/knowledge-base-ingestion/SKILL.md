# Knowledge Base Ingestion

## Purpose

Import external content into the knowledge base with a consistent structure so it can be searched and reused.

## Workflow

1. Identify the source material (book, doc, repo).
2. Extract text and structure.
3. Convert to markdown and place in the knowledge base with frontmatter.
4. Link related notes.
