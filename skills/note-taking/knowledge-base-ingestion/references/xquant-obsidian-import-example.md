# XQuant Obsidian Import Example

This example shows how a quantitative trading intro course was imported into an Obsidian vault.

## Steps

1. Extract the source document.
2. Split into chapter notes.
3. Add YAML frontmatter with tags and source.
4. Link to related concepts.

## Frontmatter Template

```yaml
---
tags: [quant, notes]
source: <source>
---
```
